# PlaceMate

A full-stack placement management platform built with Spring Boot, React, and PostgreSQL.

## Tech Stack

### Backend
- Java 21
- Spring Boot
- Spring Data JPA
- Spring Security
- Maven

### Frontend
- React
- Vite
- Axios

### Database
- PostgreSQL

### Tools
- VS Code
- Git & GitHub
- Bruno
- pgAdmin 4
